# ÉTAPE 4 — VALIDATION DES ORIENTATIONS UX

Tu es chargé de préparer et d'enregistrer la validation finale des propositions UX du workshop Localeo Live.

## 1. Charger le dossier

Identifie le répertoire daté de l'exécution en cours.

Lis :

- Le backlog UX.
- Le registre des votes.
- Le rapport exécutif.
- La galerie comparative avant/après.

Enregistre cette instruction dans :

`prompts/04-validation.md`

## 2. Préparer la revue

Présente-moi les orientations P0/P1 adoptées à la majorité.

Pour chacune, indique :

- Identifiant.
- Mission concernée.
- Problème utilisateur.
- Priorité.
- Résultat du vote.
- Capture AVANT.
- Maquette APRÈS.
- Bénéfice attendu.
- Effort estimé.
- Éventuels risques.

Présente également les problèmes critiques non résolus, même lorsqu'ils n'ont pas obtenu la majorité.

## 3. Attendre mes décisions

Pour chaque orientation, je dois pouvoir décider :

- VALIDÉE.
- REFUSÉE.
- À RÉVISER.
- REPORTÉE.

Ne présume jamais de ma décision.

Ne considère pas le vote simulé comme une validation de ma part.

## 4. Enregistrer les décisions

Crée ou complète :

`validation/decisions.md`

Pour chaque décision, indique :

- Identifiant.
- Statut.
- Date de décision si connue.
- Commentaire.
- Éventuelles conditions.
- Référence de la maquette validée.

Ne marque jamais une orientation comme validée sans mon accord explicite.

## 5. Préparer la suite

Lorsque mes décisions sont connues, prépare une liste des travaux applicatifs potentiels.

Distingue :

- Les orientations validées.
- Les orientations à réviser.
- Les orientations reportées.
- Les orientations refusées.

Ne réalise aucune implémentation.

## 6. Fin d'étape

Mets à jour le README et le statut du workshop.

Arrête-toi après l'enregistrement de mes décisions.

Attends une instruction explicite avant tout développement.
