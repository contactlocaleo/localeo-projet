# ÉTAPE 3 — PROPOSITIONS VISUELLES AVANT/APRÈS

Tu es chargé de produire les maquettes UX des orientations adoptées lors du workshop Localeo Live.

## 1. Charger les résultats

Identifie le répertoire daté de l'exécution en cours.

Lis :

- Le rapport exécutif.
- Le backlog UX.
- Les votes et arbitrages.
- Les observations factuelles.
- Les captures réelles.

Enregistre cette instruction complète dans :

`prompts/03-maquettes.md`

## 2. Périmètre

Travaille exclusivement sur les orientations :

- Adoptées à la majorité.
- Classées P0 ou P1.

Les trois missions prioritaires restent :

1. Participation aux animations.
2. Gestion des lots.
3. Calendrier des animations.

## 3. Capture AVANT

Pour chaque orientation :

- Identifie la capture réelle correspondante.
- Montre l'écran actuel.
- Localise le problème.
- Ajoute une annotation si utile.

Ne fabrique jamais une capture prétendument réelle.

Si une capture manque, tente de la réaliser avec le navigateur ou signale son absence.

## 4. Proposition APRÈS

Crée une maquette visuelle de l'écran optimisé.

Respecte :

- L'identité graphique actuelle de Localeo Live.
- Les composants existants.
- La cohérence de navigation.
- La simplicité.
- L'accessibilité.
- Les fonctionnalités déjà pertinentes.

Évite les refontes globales non justifiées.

Les maquettes doivent être produites dans des fichiers isolés du code applicatif.

## 5. Galerie comparative

Crée :

`visuels/comparatif-avant-apres.html`

La galerie doit permettre :

- Une comparaison côte à côte sur ordinateur.
- Une bascule avant/après sur mobile.
- La navigation entre les orientations.
- L'affichage des identifiants et priorités.
- L'affichage du résultat du vote.
- L'affichage du bénéfice utilisateur.
- L'affichage de l'effort estimé.

Les propositions doivent être suffisamment détaillées pour servir de référence à une implémentation ultérieure.

## 6. Revue contradictoire

Soumets les propositions aux 12 participants simulés.

Demande notamment aux habitants peu familiers du numérique :

- Comprenez-vous mieux cet écran ?
- Savez-vous où appuyer ?
- La nouvelle version est-elle plus simple ?
- Préférez-vous l'ancienne version ?
- Qu'est-ce qui reste incompréhensible ?

Les experts doivent challenger les propositions.

Si une maquette modifie substantiellement l'orientation adoptée, organise un nouveau vote selon la règle des 7 voix favorables sur 12.

Enregistre les arbitrages complémentaires.

## 7. Livrables

Dans `visuels/`, produis :

- Les captures AVANT.
- Les maquettes APRÈS.
- La galerie HTML comparative.

Mets à jour le backlog avec les références vers les maquettes.

## 8. Contraintes

- Aucune modification du code applicatif.
- Aucune implémentation.
- Aucune modification non votée du périmètre.
- Aucune suppression de fonctionnalité sans justification.

Mets à jour le README.

Arrête-toi après la production des maquettes et attends ma validation.
