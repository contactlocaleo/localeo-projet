# ÉTAPE 4 — VALIDATION UX MARKETPLACE LOCALEO

Tu es chargé de préparer la validation finale des orientations UX de la marketplace Localeo.

## 1. Charger les livrables

Identifie le répertoire daté de l'exécution en cours.

Lis :

- Le rapport exécutif.
- Le backlog.
- Les votes.
- Les comparatifs avant/après.
- Les risques critiques non résolus.

Enregistre ce prompt dans `prompts/04-validation.md`.

## 2. Présenter les orientations

Pour chaque orientation P0/P1 adoptée, présente :

- ID.
- Parcours concerné.
- Problème.
- Conséquence utilisateur.
- Priorité.
- Résultat du vote.
- Capture AVANT.
- Maquette APRÈS.
- Bénéfice attendu.
- Effort estimé.
- Risques et dépendances.

Présente séparément les risques critiques non résolus.

## 3. Attendre ma décision

Je dois pouvoir décider pour chaque orientation :

- VALIDÉE.
- REFUSÉE.
- À RÉVISER.
- REPORTÉE.

Ne présume jamais de ma décision.

Le vote simulé ne constitue pas ma validation.

## 4. Enregistrer les décisions

Crée ou complète :

`validation/decisions.md`

Pour chaque orientation :

- ID.
- Statut.
- Date si connue.
- Commentaire.
- Conditions.
- Référence de la maquette.

Ne marque aucune orientation comme validée sans accord explicite.

## 5. Préparer la suite

Produis un backlog d'implémentation potentiel distinguant :

- Orientations validées.
- Orientations à réviser.
- Orientations reportées.
- Orientations refusées.

Ne réalise aucune implémentation.

## 6. Contraintes

Aucune modification applicative.

Aucun paiement.

Aucune implémentation automatique.

Mets à jour le README et arrête-toi après l'enregistrement de mes décisions.
