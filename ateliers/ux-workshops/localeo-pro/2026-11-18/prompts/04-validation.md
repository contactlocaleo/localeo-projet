# ÉTAPE 4 — VALIDATION UX LOCALEO PRO

Tu es chargé de préparer la validation finale des orientations UX proposées pour Localeo Pro.

## 1. Charger le dossier

Identifie le répertoire daté de l'exécution en cours.

Lis :

- Le rapport exécutif.
- Le backlog.
- Les votes.
- Les comparatifs avant/après.
- Les éventuels risques critiques non résolus.

Enregistre cette instruction dans `prompts/04-validation.md`.

## 2. Présenter les orientations

Pour chaque P0/P1 adoptée, présente :

- Identifiant.
- Mission concernée.
- Problème.
- Conséquence pour le commerçant.
- Priorité.
- Résultat du vote.
- Capture AVANT.
- Maquette APRÈS.
- Bénéfice attendu.
- Effort estimé.
- Risques et dépendances.

Présente séparément les risques critiques non résolus, y compris les sujets rejetés par le vote.

## 3. Attendre ma décision

Pour chaque orientation, je dois pouvoir décider :

- VALIDÉE.
- REFUSÉE.
- À RÉVISER.
- REPORTÉE.

Ne présume jamais de ma décision.

Les votes simulés ne constituent pas une validation de ma part.

## 4. Enregistrer les décisions

Crée ou complète :

`validation/decisions.md`

Pour chaque orientation :

- ID.
- Statut.
- Date si connue.
- Commentaire.
- Conditions éventuelles.
- Référence de la maquette.

Ne marque aucune orientation comme validée sans accord explicite.

## 5. Préparer les travaux futurs

Produis une synthèse distinguant :

- Les orientations validées.
- Les orientations à réviser.
- Les orientations reportées.
- Les orientations refusées.

Prépare un backlog d'implémentation potentiel, sans exécuter de développement.

## 6. Contraintes

Aucune modification applicative.

Aucune implémentation automatique.

Mets à jour le README.

Arrête-toi après l'enregistrement de mes décisions.
