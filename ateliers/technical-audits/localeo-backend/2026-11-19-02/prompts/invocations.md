# Messages réellement transmis

Le registre messages-exacts.json contient les messages d'invocation et compléments exacts, avec les cibles, fork_turns=none, remplacement et refus initial par limite de threads. Les briefs référencés étaient écrits avant les appels. Aucun des six anciens prompts d'étape n'est présenté comme invoqué ici.

Sept missions spécialistes ont été créées : CPU, mémoire, concurrence, persistance initiale interrompue, API, persistance indépendante de remplacement, SRE. Six premières analyses indépendantes ont été retenues. Un contradicteur réel distinct a ensuite reçu les propositions et leurs sources. Les votes du rapport sont une simulation de l'orchestrateur, pas des messages d'accord des agents.

La première note de transcription de ces messages avait perdu des caractères accentués lors d'un passage PowerShell/Python. Elle est remplacée par cet index et le registre JSON écrit directement en UTF-8 ; les textes du registre sont ceux des appels visibles dans la conversation. Les corps des briefs et le prompt joint n'ont pas été reconstruits depuis les anciens audits. La pièce jointe originale est aussi conservée octet pour octet dans 00-piece-jointe-originale.txt, avec empreinte dans validation/prompt-provenance.json.
