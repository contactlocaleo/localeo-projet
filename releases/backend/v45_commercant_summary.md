# Localeo V45 - Fiche commerçant enrichie

Cette version enrichit la fiche détail commerçant dans SQLAdmin.

## Ajouts
- résumé synthétique du commerçant
- ville, type et contact visibles en un coup d'œil
- liste des prestations portées par le commerçant
- liste dédupliquée des coffrets auxquels il participe

## Résultat
Dans la fiche commerçant, on voit directement :
- son identité métier
- les prestations qu'il propose dans le catalogue
- les coffrets dans lesquels il intervient
