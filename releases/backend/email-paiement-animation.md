# Mail de paiement Localeo Animation

Le mail `PAIEMENT_ABONNEMENT_ANIMATION` reprend la charte des autres emails
Localeo : logo, en-tête bleu, montant TTC mis en avant et bouton orange
« Régler mon abonnement ». Le détail des offres par commune et le lien Stripe
sont conservés. Le texte précise que les accès sont activés après confirmation
du paiement par Stripe. Une version texte et un lien de secours restent fournis.

Le modèle s'applique aux prochains emails préparés, y compris les renvois
explicites. Les messages déjà en file ne sont pas modifiés ni renvoyés.
Aucun changement des applications clientes ou des contrats API n'est requis.
