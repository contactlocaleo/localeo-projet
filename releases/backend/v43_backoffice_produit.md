# Localeo V43 - Back-office produit

Cette version enrichit le back-office SQLAdmin pour une lecture plus métier.

## Améliorations
- icônes sur les vues principales
- badges visuels pour les statuts et types
- affichage des prix en euros
- détail enrichi des coffrets avec les prestations du coffret
- lecture plus claire pour l'exploitation catalogue

## Effet attendu
Dans la fiche d'un coffret, on peut visualiser plus facilement :
- son type
- son prix
- sa durée de validité
- les prestations associées
- les commerçants liés aux prestations
