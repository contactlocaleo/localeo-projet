# Versions juridiques de travail

Livrables historiques provenant de `localeo-backend/output/pdf` et `output/docx`. Aucune approbation ou publication ne découle de leur présence ici. Le [catalogue juridique](../../../docs/juridique/publication/catalogue.json) demeure la référence des documents à publier. Ne pas remplacer un texte approuvé par un de ces livrables sans validation explicite.
