# Registre des arbitrages API - EPIC 41 Animation locale

> Consolidation documentaire du 18 septembre 2026 : les contributions Backend et Animation sont réunies. Les validations historiques sont conservées avec leur provenance ; la divergence sur les aperçus privés des flyers ne reçoit aucun arbitrage supplémentaire.

## Objet

Ce document centralise les décisions enregistrées pour les contrats API de l’EPIC 41. L’EPIC reste terminée selon la [roadmap commune](../../roadmap/terminees/epic-41-plateforme-animation-locale-mvp-backlog.md). Les formulations historiques contradictoires sont identifiées ci-dessous ; elles ne créent ni nouvel identifiant d’arbitrage ni nouveau statut produit.

Mode d'utilisation de la derniere colonne :

- cocher `[x] Validee` lorsque la proposition est acceptee ;
- remplacer ou completer `Amendement :` lorsque la proposition doit evoluer ;
- ajouter la date et, si necessaire, le decisionnaire.
