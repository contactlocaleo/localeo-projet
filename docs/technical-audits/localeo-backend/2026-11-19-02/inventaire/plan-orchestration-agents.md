# Orchestration et indépendance

Six véritables spécialistes créés avec fork_turns=none : CPU, mémoire, async/concurrence, persistance, API, SRE. Maximum trois spécialistes simultanés en plus de l'orchestrateur, deux vagues. Première analyse sans lecture d'anciens verdicts ni des rapports des autres. Chaque spécialiste lit lui-même le code et possède seulement son rapport numéroté et son annexe. Les prompts exacts et messages d'invocation sont conservés dans prompts/.

Aucun agent ne possède serveur/base/benchmark ; l'orchestrateur est seul exécutant. Après finalisation des six rapports, consolidation par cause/flux puis contradicteur réel indépendant. Le contradicteur reçoit les propositions et preuves, pas une mission de confirmer. Les éventuels votes sont explicitement simulés, sans pouvoir de preuve ou d'autorisation.

Pas d'implémentation ni migration ; aucun commit/push/déploiement. Les choix utilisateur resteront vides. Priorité Live et plateforme Animation ; dépendances partagées ERP/outbox conservées lorsque leur effet sur ces parcours est expliqué.
