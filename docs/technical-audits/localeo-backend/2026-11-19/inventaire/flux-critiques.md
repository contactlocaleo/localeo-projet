# Flux critiques et chaînes d’exécution

Sources lues directement ; références rattachées au commit du [README](../README.md). Les chemins sont ceux du backend. Les coûts ne sont pas encore mesurés. Les identifiants F01–F12 serviront — relier missions, causes racines et API. Pour chaque chaîne : entrée — handler — application — stockage — traitements — réponse. Les dépendances d’accès font partie du coût futur — mesurer.

Invariant — préserver lors d’une optimisation : pas de double consommation, QR révoqué refusé, rattachement commerçant et transaction valide ; autorité dans les entités/services du domaine appelés par le use case.
