# ADR

Ce dossier regroupe les Architecture Decision Records.

Un ADR doit etre cree lorsqu'une decision :

- impacte plusieurs domaines fonctionnels ;
- modifie une convention transverse ;
- a des consequences durables sur les API, les donnees, le back-office ou l'exploitation ;
- merite d'etre comprise independamment d'une EPIC.

Utiliser le template [adr-template.md](../templates/adr-template.md).
