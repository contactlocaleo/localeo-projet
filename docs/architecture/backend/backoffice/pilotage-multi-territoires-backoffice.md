# Pilotage multi-territoires du BackOffice

L'entrée **Pilotage > Périmètre territorial** permet de choisir une commune ou « Tous les territoires ». Le choix est conservé dans la session de l'administrateur jusqu'à sa déconnexion ou jusqu'à un nouveau choix.

Le périmètre filtre : commerçants, coffrets, prestations, achats, instances, paiements, consommations, validations, mouvements et reversements. Les objets indirects sont rattachés à la commune par leur coffret ou leur commerçant ; aucune nouvelle notion de territoire n'est créée.

Le dashboard affiche toujours le territoire actif. Lorsqu'une commune est sélectionnée, il ne présente que les indicateurs commerciaux et alertes pouvant être rattachés sans ambiguïté à cette commune. Les alertes purement globales d'exploitation restent disponibles avec « Tous les territoires ».

Pour diagnostiquer deux objets de même nom, vérifier le territoire affiché dans l'en-tête avant toute action. Revenir explicitement à « Tous les territoires » pour obtenir une vision consolidée.
