# ÉTAPE 3 — MAQUETTES UX LOCALEO CRM

Tu es chargé de produire les propositions visuelles des orientations UX adoptées lors du workshop Localeo CRM.

## 1. Charger les résultats

Identifie le répertoire daté de l'exécution en cours.

Lis :

- Le rapport exécutif.
- Le backlog.
- Les votes.
- Les observations factuelles.
- Les captures réelles.

Enregistre ce prompt dans `prompts/03-maquettes.md`.

## 2. Périmètre

Travaille uniquement sur les orientations :

- Adoptées à au moins 7 voix sur 12.
- Classées P0 ou P1.

Les domaines prioritaires sont :

- Tableau de bord.
- Pipeline.
- Qualification.
- Fiches prospects.
- Rendez-vous.
- Agenda.
- Tâches et relances.
- Collaboration.

## 3. Captures AVANT

Pour chaque orientation :

- Utilise une capture réelle.
- Identifie l'écran.
- Montre le problème.
- Annote si nécessaire.
- Référence l'observation et le vote.

Ne fabrique pas de capture réelle.

## 4. Maquettes APRÈS

Produis une proposition visuelle respectant :

- L'identité graphique Localeo.
- Les composants existants.
- La cohérence de navigation.
- La simplicité.
- L'accessibilité.
- La lisibilité des données.
- La productivité commerciale.

Privilégie les modifications à fort bénéfice et effort maîtrisé.

Évite les tableaux de bord surchargés et les indicateurs sans utilité opérationnelle.

Les maquettes doivent être isolées du code applicatif.

## 5. Scénarios visuels

Selon les orientations adoptées, illustre :

- L'accueil.
- Le tableau de bord.
- Le pipeline.
- La liste des prospects.
- La fiche prospect.
- La qualification.
- L'agenda.
- Le rendez-vous.
- Les tâches.
- Les relances.
- La collaboration.

Ne crée pas de propositions sans orientation adoptée.

## 6. Galerie comparative

Crée :

`visuels/comparatif-avant-apres.html`

Pour chaque orientation :

- ID.
- Priorité.
- Parcours.
- Problème.
- Capture AVANT.
- Maquette APRÈS.
- Bénéfice.
- Effort estimé.
- Résultat du vote.

Prévois une comparaison côte à côte sur ordinateur et une bascule avant/après sur mobile.

## 7. Revue contradictoire

Soumets les maquettes aux cinq experts et sept utilisateurs simulés.

Demande :

- Comprenez-vous mieux l'état de la prospection ?
- Les prochaines actions sont-elles plus visibles ?
- La qualification est-elle plus simple ?
- Les rendez-vous sont-ils plus faciles à gérer ?
- Les risques d'oubli sont-ils réduits ?
- Préférez-vous l'ancienne ou la nouvelle version ?

Les réactions restent simulées.

Si une proposition modifie substantiellement l'orientation adoptée, organise un nouveau vote.

## 8. Livrables

Enregistre :

- Les captures réelles.
- Les maquettes.
- La galerie comparative.
- Les arbitrages complémentaires.

Mets à jour le backlog avec les références visuelles.

## 9. Contraintes

Aucune modification applicative.

Aucune implémentation.

Aucune modification non votée du périmètre.

Mets à jour le README et attends ma validation.
