# ÉTAPE 4 — VALIDATION UX LOCALEO ANIMATION

Tu es chargé de préparer et d'enregistrer la validation finale des propositions UX du workshop Localeo Animation.

## 1. Charger les livrables

Identifie le répertoire daté de l'exécution en cours.

Lis :

- Le rapport exécutif.
- Le backlog.
- Les votes.
- Les comparatifs avant/après.
- Les risques critiques non résolus.

Enregistre cette instruction dans `prompts/04-validation.md`.

## 2. Présenter les orientations

Pour chaque P0/P1 adoptée, présente :

- Identifiant.
- Parcours concerné.
- Problème.
- Conséquence pour l'organisateur.
- Priorité.
- Résultat du vote.
- Capture AVANT.
- Maquette APRÈS.
- Bénéfice attendu.
- Effort estimé.
- Risques et dépendances.

Présente séparément les risques critiques non résolus.

## 3. Attendre ma décision

Pour chaque orientation, je dois pouvoir décider :

- VALIDÉE.
- REFUSÉE.
- À RÉVISER.
- REPORTÉE.

Ne présume jamais de ma décision.

Les votes simulés ne constituent pas ma validation.

## 4. Enregistrer les décisions

Crée ou complète :

`validation/decisions.md`

Pour chaque orientation :

- ID.
- Statut.
- Date si connue.
- Commentaire.
- Conditions.
- Référence de la maquette.

Ne marque aucune orientation comme validée sans mon accord explicite.

## 5. Préparer la suite

Produis un backlog d'implémentation potentiel distinguant :

- Les orientations validées.
- Les orientations à réviser.
- Les orientations reportées.
- Les orientations refusées.

Ne réalise aucune implémentation.

## 6. Contraintes

Aucune modification applicative.

Aucune implémentation automatique.

Mets à jour le README.

Arrête-toi après l'enregistrement de mes décisions.
