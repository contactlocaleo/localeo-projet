# ÉTAPE 3 — PROPOSITIONS VISUELLES UX LOCALEO ANIMATION

Tu es chargé de produire les maquettes UX des orientations retenues lors du workshop Localeo Animation.

## 1. Charger le contexte

Identifie le répertoire daté de l'exécution en cours.

Lis :

- Le rapport exécutif.
- Le backlog.
- Les votes.
- Les observations.
- Les captures réelles.

Enregistre cette instruction complète dans `prompts/03-maquettes.md`.

## 2. Périmètre

Travaille exclusivement sur les orientations :

- Adoptées à la majorité de 7 voix sur 12.
- Classées P0 ou P1.

Les cinq domaines prioritaires sont :

- Création et publication.
- Onboarding commerçants.
- Suivi des animations.
- Clôture et bilan.
- Pilotage opérationnel global.

## 3. Captures AVANT

Pour chaque orientation :

- Utilise une capture réelle.
- Identifie l'écran.
- Montre le problème.
- Ajoute une annotation si nécessaire.
- Référence l'observation et le vote.

Ne fabrique jamais une capture réelle.

## 4. Maquettes APRÈS

Produis une proposition visuelle respectant :

- L'identité graphique actuelle.
- Les composants existants.
- La cohérence de navigation.
- La simplicité.
- L'accessibilité.
- L'autonomie des organisateurs.

Privilégie les modifications à fort bénéfice et effort maîtrisé.

Ne propose pas de refonte globale non justifiée.

Les maquettes doivent être isolées du code applicatif.

## 5. Scénarios à illustrer

Selon les orientations P0/P1 adoptées, illustre notamment :

- L'accueil organisateur.
- Le démarrage d'une création.
- Les étapes de paramétrage.
- La prévisualisation.
- La publication.
- L'ajout et l'import de commerçants.
- Le suivi des invitations.
- Le tableau de bord d'animation.
- La clôture.
- Le bilan.
- Le pilotage multi-animations.

Ne crée pas artificiellement de propositions sans orientation adoptée.

## 6. Galerie comparative

Crée :

`visuels/comparatif-avant-apres.html`

Elle doit présenter :

- ID.
- Parcours.
- Priorité.
- Problème.
- Capture AVANT.
- Maquette APRÈS.
- Bénéfice attendu.
- Effort estimé.
- Résultat du vote.

Prévois un affichage côte à côte sur ordinateur et une bascule avant/après sur mobile.

## 7. Revue contradictoire

Soumets les maquettes aux cinq experts et sept utilisateurs métier simulés.

Demande :

- La nouvelle version est-elle plus claire ?
- Le parcours est-il plus simple ?
- Les actions sont-elles plus visibles ?
- Les risques d'erreur sont-ils réduits ?
- L'ancienne ou la nouvelle version est-elle préférable ?
- Quelles difficultés restent présentes ?

Les réactions doivent être identifiées comme simulées.

Si une maquette modifie substantiellement l'orientation adoptée, organise un nouveau vote.

## 8. Livrables

Enregistre :

- Les captures réelles dans `visuels/captures-avant/`.
- Les maquettes dans `visuels/maquettes-apres/`.
- La galerie HTML.
- Les arbitrages complémentaires.

Mets à jour le backlog avec les références.

## 9. Contraintes et arrêt

Aucune modification du code applicatif.

Aucune implémentation.

Aucune orientation non votée ajoutée au périmètre.

Mets à jour le README.

Arrête-toi et attends ma validation.
