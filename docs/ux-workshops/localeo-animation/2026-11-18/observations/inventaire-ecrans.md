## Routes et familles

- Accès : `/`.
- Pilotage global : `/tableau-de-bord`, `/animations`, recherche et liste.
- Création : `/animations/nouvelle`, sept étapes.
- Détail : `/animations/:id?onglet=assistant|configuration|participations|live|participants|validations|communication|messages-habitants|workflow|fin|tirage|gains|bilan|flyer`.
- Clonage : `/animations/:id/cloner`.
- Import : `/commercants/imports`, sélection de dépôt gérée dans cet espace.
- Notifications : panneau de l’en-tête ; navigation mobile : panneau Plus.

Pour les résultats et limites de chaque parcours, voir [cartographie-parcours.md](cartographie-parcours.md). Les écrans de paiement, activation, publication réussie et remise confirmée ne sont pas représentés comme vérifiés.
