# ÉTAPE 5 — ARCHIVAGE ET REJOUABILITÉ DU WORKSHOP LOCALEO PRO

Tu es chargé de finaliser l'archivage du workshop UX Localeo Pro.

## 1. Répertoire de référence

Identifie l'exécution en cours dans :

`docs/ux-workshops/localeo-pro/YYYY-MM-DD/`

Ne modifie pas les répertoires des exécutions précédentes.

## 2. Vérification des prompts

Contrôle la présence et le contenu de :

- `prompts/00-protocole-global.md`
- `prompts/01-exploration.md`
- `prompts/02-workshop.md`
- `prompts/03-maquettes.md`
- `prompts/04-validation.md`
- `prompts/05-archivage.md`

Chaque fichier doit contenir le prompt complet réellement utilisé.

Enregistre cette instruction dans `prompts/05-archivage.md`.

Si une instruction a évolué, conserve la version finale et documente les modifications.

Si le contenu exact d'un prompt est indisponible, signale-le sans inventer de version historique.

## 3. Vérifier les livrables

Contrôle :

- Les observations factuelles.
- Les cartographies.
- Les captures.
- Les rapports.
- Les votes nominatifs.
- Le backlog.
- Les orientations rejetées.
- Les quick wins.
- Les maquettes.
- La galerie HTML.
- Les décisions de validation.
- La roadmap.
- Le plan de tests commerçants.

Signale les éléments manquants.

## 4. Compléter les livrables de synthèse

Crée dans `synthese/` :

- `roadmap-ux.md`
- `plan-tests-commercants.md`

La roadmap doit distinguer :

- Avant lancement : P0/P1 validées.
- Après premiers retours : P2 et ajustements.
- Évolutions futures : P3.

Le plan de tests doit prévoir au moins cinq scénarios réels avec des commerçants, dont deux peu familiers du numérique.

Définis les tâches, les consignes neutres, les critères de réussite et les observations à recueillir.

## 5. Finaliser le README

Indique :

- Date et heure.
- URL analysée.
- Branche et commit Git.
- Modèles et niveaux de raisonnement connus.
- Version du protocole.
- Parcours réellement vérifiés.
- Limitations.
- Nombre d'orientations proposées.
- Nombre d'orientations adoptées.
- Nombre de P0/P1.
- Statut des validations.
- Liste des livrables.
- État final : terminé, partiel ou interrompu.

## 6. Comparaison historique

Si un workshop Localeo Pro précédent existe, crée :

`synthese/comparaison-precedent.md`

Compare :

- Les problèmes corrigés.
- Les problèmes persistants.
- Les nouveaux problèmes.
- Les changements de priorité.
- Les évolutions des notes heuristiques.
- Les orientations validées ou reportées.

Ne présente comme corrigés que les problèmes dont la résolution a été réellement vérifiée.

## 7. Préparer la relance

Crée :

`prompts/RELANCER-WORKSHOP.md`

Ce prompt doit être autonome et permettre de :

1. Identifier le dernier protocole.
2. Créer un nouveau répertoire daté.
3. Réexplorer l'application.
4. Simuler le workshop.
5. Organiser les votes à la majorité.
6. Prioriser P0 à P3.
7. Produire les comparatifs visuels.
8. Comparer les résultats avec les précédents.
9. Préserver l'historique.
10. Attendre ma validation.

## 8. Vérification finale

Vérifie :

- L'intégrité des fichiers.
- Les chemins relatifs.
- Les captures.
- Les maquettes.
- Les prompts.
- La préservation des exécutions précédentes.
- L'absence de modification du code applicatif.

Si le workshop est incomplet, indique-le explicitement.

## 9. Restitution

Présente :

- Le chemin du répertoire archivé.
- Le statut final.
- Les principaux livrables.
- Les éventuelles anomalies.
- Le chemin du prompt de relance.

Ne réalise aucune modification applicative.
