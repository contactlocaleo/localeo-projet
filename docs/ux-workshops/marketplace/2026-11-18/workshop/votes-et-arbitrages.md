## Arguments individuels

### O-01 — Définir le coffret sur le premier écran mobile (11/12)

- **Experts :** A +, le CTA gagnera en contexte ; B +, l'offre devient plus immédiatement désirable ; C −, risque d'alourdir l'entrée ; D +, « coffret par e-mail » est polysémique ; E +, formulation courte à tester.
- **Profils :** F +, veut savoir ce qu'elle offre ; G +, veut voir « local » et « cadeau » ensemble ; H +, cherche où se vivent les moments ; I +, veut séparer coffrets et animations ; J +, veut décider vite ; K +, veut voir les partenaires nommés ; L +, veut pouvoir l'expliquer en une phrase.

### O-02 — Délimiter garantie et exemples (12/12)

- **Experts :** A +, résumé près du prix ; B +, réduit l'incertitude d'achat ; C +, préserve la souplesse contractuelle si l'on nomme les exemples ; D +, mots simples et exacts ; E +, hypothèse centrale à valider ensuite.
- **Profils :** F +, évite de croire que les deux exemples sont dus ; G +, compare une promesse réelle ; H +, tient compte des disponibilités ; I +, distingue d'une animation datée ; J +, compare contenu et prix ; K +, protège la fidélité de sa prestation ; L +, clarifie ce qu'il doit réaliser.

### O-03 — Parcours du cadeau avant achat (10/12)

- **Experts :** A +, réduit l'hésitation au formulaire ; B +, répond à une objection de conversion ; C +, reste dans le MVP ; D +, clarifie l'e-mail et le téléphone ; E +, à confronter à Marie et Sophie réelles.
- **Profils :** F +, veut savoir quel e-mail saisir ; G +, veut connaître l'envoi de la carte ; H +, achète à distance ; I −, n'achète pas de coffret dans son scénario ; J +, attend une séquence courte ; K −, préfère d'abord sécuriser la promesse des prestations ; L +, veut expliquer le cadeau au comptoir.

### O-04 — Entrée commune plus lisible (8/12)

- **Experts :** A +, réduit le décodage des catégories ; B −, prioriserait le coffret ; C +, le territoire est une porte d'entrée produit ; D +, intitulé explicite ; E +, changement léger à tester.
- **Profils :** F +, partirait de sa commune ; G +, cherche sa ville ; H +, découvre une destination ; I −, utilise déjà l'agenda ; J +, veut garder le filtre au retour ; K −, préfère sa fiche commerce ; L −, n'a pas constaté de blocage dans son scénario.

### O-05 — Contrôle éditorial des fiches publiées (9/12)

- **Experts :** A −, ne veut pas prioriser un redesign depuis TEST ; B +, un placeholder public nuit à la confiance ; C +, exige un contrôle conditionné à l'environnement publié ; D +, exactitude et lisibilité ; E +, faire vérifier par des partenaires réels.
- **Profils :** F +, a besoin d'adresses crédibles ; G +, l'idée cadeau dépend des commerces ; H +, prépare une visite ; I −, consulte surtout les animations ; J −, préfère une comparaison de coffrets ; K +, exige une prestation fidèle ; L +, veut une présentation juste de sa boutique.

### O-06 — Nommer la transition vers Live (8/12)

- **Experts :** A +, le lien doit annoncer sa destination ; B +, réduit une possible rupture ; C −, le filtre communal transmis suffit peut-être ; D +, « voir » et « s'inscrire » doivent différer ; E +, petite intervention à tester.
- **Profils :** F +, veut savoir pourquoi une autre page s'ouvre ; G −, reconnaîtrait probablement Localeo ; H −, accepte Live si la commune est gardée ; I +, cherche à participer ; J −, changement de domaine habituel pour elle ; K +, veut comprendre où apparaît son animation ; L +, veut guider un client occasionnel.

### O-07 — Conditions avant l'action finale (10/12)

- **Experts :** A +, regroupe les informations décisives ; B +, peut réduire l'hésitation ; C −, craint de dupliquer la fiche ; D +, CGV et validité doivent être trouvables ; E +, sans prétendre mesurer l'abandon.
- **Profils :** F +, vérifie la durée ; G +, veut offrir en connaissance de cause ; H +, cherche les conditions de réservation ; I −, n'achète pas dans ce scénario ; J +, attend prix et termes au même endroit ; K +, veut éviter une promesse excessive ; L +, veut des règles faciles à expliquer.

### O-08 — Recette contrôlée du passage Stripe (12/12)

- **Experts :** A +, vérifier l'interface après le bouton ; B +, le point de conversion est inconnu ; C +, porte de lancement ; D +, vérifier aussi les messages d'erreur ; E +, protocole autorisé sans achat réel.

### O-10 — Intégrer tout Live dans Marketplace maintenant (6/12)

- **Experts :** A −, coût et duplication ; B +, un seul domaine pourrait rassurer ; C −, Live porte déjà la participation ; D +, moins de rupture cognitive ; E −, besoin à confirmer avec de vrais visiteurs.
