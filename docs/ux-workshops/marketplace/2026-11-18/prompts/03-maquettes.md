# ÉTAPE 3 — MAQUETTES UX MARKETPLACE LOCALEO

Tu es chargé de produire les propositions visuelles des orientations UX adoptées lors du workshop marketplace Localeo.

## 1. Charger les résultats

Identifie le répertoire daté de l'exécution en cours.

Lis :

- Le rapport exécutif.
- Le backlog.
- Les votes.
- Les observations factuelles.
- Les captures réelles.

Enregistre ce prompt dans `prompts/03-maquettes.md`.

## 2. Périmètre

Travaille uniquement sur les orientations :

- Adoptées à au moins 7 voix sur 12.
- Classées P0 ou P1.

Les domaines prioritaires sont :

- Accueil et première impression.
- Découverte des communes.
- Présentation des commerçants.
- Découverte et détail des coffrets.
- Calendrier des animations.
- Parcours d'achat jusqu'à Stripe.
- Réassurance et compréhension de l'offre.

## 3. Captures AVANT

Pour chaque orientation :

- Utilise une capture réelle.
- Identifie l'écran.
- Montre le problème.
- Annote si nécessaire.
- Référence l'observation et le vote.

Ne fabrique pas de capture réelle.

## 4. Maquettes APRÈS

Produis une proposition visuelle respectant :

- L'identité graphique Localeo.
- Les composants existants.
- La cohérence entre les pages.
- La simplicité.
- L'accessibilité.
- La lisibilité mobile.
- La valorisation des expériences locales.

Privilégie les changements simples et efficaces.

Ne transforme pas Localeo en marketplace générique de produits matériels.

Les maquettes doivent préserver le positionnement de coffrets d'expériences locales.

Ne modifie aucun code applicatif.

## 5. Scénarios visuels

Selon les orientations adoptées, illustre notamment :

- La page d'accueil.
- La sélection d'une commune.
- La page d'une commune.
- La fiche commerçant.
- La liste des coffrets.
- Le détail d'un coffret.
- Le calendrier.
- Le détail d'une animation.
- Le récapitulatif d'achat.
- La transition vers Stripe.

Ne crée pas de propositions sans orientation adoptée.

## 6. Galerie comparative

Crée :

`visuels/comparatif-avant-apres.html`

Pour chaque orientation, présente :

- ID.
- Priorité.
- Parcours.
- Problème.
- Capture AVANT.
- Maquette APRÈS.
- Bénéfice.
- Effort estimé.
- Résultat du vote.

Prévois une comparaison côte à côte sur ordinateur et une bascule avant/après sur mobile.

## 7. Revue contradictoire

Soumets les maquettes aux cinq experts et sept utilisateurs simulés.

Demande :

- Comprenez-vous mieux la proposition de valeur ?
- La nouvelle version facilite-t-elle la découverte ?
- Les coffrets sont-ils plus compréhensibles ?
- Les commerçants sont-ils mieux mis en valeur ?
- L'achat paraît-il plus simple et rassurant ?
- Préférez-vous l'ancienne ou la nouvelle version ?

Les réactions restent simulées.

Si une proposition modifie substantiellement l'orientation adoptée, organise un nouveau vote.

## 8. Livrables

Enregistre :

- Les captures réelles.
- Les maquettes.
- La galerie comparative.
- Les arbitrages complémentaires.

Mets à jour le backlog avec les références visuelles.

## 9. Contraintes

Aucune modification applicative.

Aucune implémentation.

Aucun paiement.

Mets à jour le README et attends ma validation.
