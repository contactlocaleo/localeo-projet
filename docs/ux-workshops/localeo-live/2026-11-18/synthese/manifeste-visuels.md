# Manifeste des visuels

Toutes les captures AVANT sont des PNG de l’application réelle explorée pour Bouliac. Les exports APRÈS sont des maquettes locales ; les états personnels fictifs sont signalés dans leurs planches et la [référence](../visuels/reference-maquettes.md). Les empreintes permettent de repérer une révision, sans constituer une preuve de comportement.
