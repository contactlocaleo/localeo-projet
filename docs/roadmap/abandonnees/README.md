# Epics abandonnees

[Retour a la roadmap](../README.md)

Deux perimetres historiques sont abandonnes ou decommissionnes :

- Epic 5 : authentification par QR commercant explicitement abandonnee,
  remplacee par le login/mot de passe de l'Epic 10. Le QR coffret reste utilise.
- Epic 12 : export et paiement bancaire manuel decommissionnes par l'Epic 39,
  au profit de Stripe Connect ; aucune reactivation en fallback n'est prevue.

Leurs anciens statuts « Termine » sont corriges d'apres les decisions deja
inscrites dans les backlogs. Les details sont conserves pour l'historique.
L'Epic 61 est fusionnee dans l'Epic 60, et n'est pas un abandon.
