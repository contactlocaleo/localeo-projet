# Supports de formation Localeo

## Objectif

Ce répertoire rassemble les documents destinés à la prise en main et à la
montée en compétence des utilisateurs de Localeo. Une formation explique les
concepts et parcours ; pour traiter un incident réel, utiliser ensuite la
procédure correspondante dans `exploitation/` ou `technique/`.

## Parcours conseillé

1. Lire le guide de prise en main ERP pour comprendre les menus actuels et les rôles ; les sections SQLAdmin du guide de référence concernent l'administration historique.
2. Parcourir le référencement, la commercialisation et les achats.
3. Étudier le support, les validations et les reversements.
4. Réaliser les exercices sur un environnement de recette.
5. Utiliser la base de connaissance opérationnelle pour les cas réels.
