# Hero d’accueil — dégustation chez la fromagère

La photo 22, choisie pour le hero, montre deux clients profitant d’une dégustation accompagnée par une fromagère. La rue passante, les boutiques traditionnelles et contemporaines et le marché en arrière-plan évoquent une commune française inspirée de Latresne.

Image synthétique créée avec l’outil intégré image_gen, sans représentation d’un commerce partenaire réel. Le hero utilise désormais la version aux détails améliorés : `output/hero-variantes/22-degustation-fromager-rue-vivante-detail-v2.png`. Sa définition native reste de 1774 × 887 pixels.

- Ordinateur : `public/img/hero-fromager-v35-1774.webp` (1774 × 887, 543 708 octets).
- Mobile et tablette jusqu’à 980 px : `public/img/hero-fromager-v35-960.webp` (960 × 480, 172 938 octets).
- Encodage WebP par canvas Chromium, qualité 0,94 sur ordinateur et 0,90 sur mobile pour préserver les détails. Les nouveaux noms de fichiers renouvellent le cache navigateur.
- Cadrage orienté vers la dégustation à droite ; description accessible dans `AccueilPage.jsx`.

Les tests visuels F14 vérifient l’affichage et le chargement de la variante appropriée à 390, 800 et 1440 px ainsi que le budget de poids des fichiers.
