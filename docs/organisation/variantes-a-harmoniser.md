## Divergences explicites conservées dans les documents consolidés

- Les versions Backend et Animation de l'EPIC 41 divergent sur les aperçus privés des flyers avant publication : consulter le [registre EPIC 41](../specifications/epic-41-api/registre-arbitrages.md) et ANI-PART-ARB-11 dans le [registre EPIC 56](../specifications/epic-56-validation-participation-commercants-animation/registre-arbitrages.md).
- La description historique de l'espace commerçant mentionne un QR d'authentification de secours, alors que l'EPIC 5 est abandonnée au profit de l'EPIC 10. L'écart est conservé dans la [vue commerçant](../specifications/espace-commercant/README.md).

Aucune de ces divergences n'a été résolue par un nouvel arbitrage implicite.
